# FedSum 三随机种子原任务验证（2026-09-22）

## 协议

CNN/DM 2K训练样本，PreSumm+CoreNLP预处理，Dirichlet 0.1，20客户端，
每轮抽取4客户端，每客户端2个local epochs，共5轮。FedAvg与FedSum在
seed 666、123、2025下成对运行。每个运行按论文做法取通信轮中的最佳测试记录。

## 结果

| 方法 | R1-F | R2-F | RL-F |
|---|---:|---:|---:|
| 论文 FedAvg | 34.11 | 12.87 | 27.17 |
| 本次 FedAvg 三种子均值 | 33.82 ± 4.09 | 12.13 ± 3.17 | 30.65 ± 3.94 |
| 论文 FedSum | 35.71 | 14.18 | 28.69 |
| 本次 FedSum 三种子均值 | 33.89 ± 4.24 | 12.20 ± 3.35 | 30.66 ± 4.14 |
| 本次 FedSum−FedAvg | +0.08 | +0.06 | +0.01 |
| 论文 FedSum−FedAvg | +1.60 | +1.31 | +1.52 |

## 结论

FedSum的三种子均值略高于FedAvg，但优势只有0.01–0.08分，远小于论文的
1.31–1.60分；而且两个种子没有出现稳定优势，种子方差明显大于算法差异。
因此，本次验证没有复现论文的核心结论“FedSum稳定优于FedAvg”。正确身份仍为：

> 基于不完整官方源码的修复性独立复现；原任务核心趋势未通过验证。

FedSum不应进入CAIL正式基线表。紧凑证据包为
`fedsum_multiseed_validation_compact.tgz`。
