# Requirement sets

- `core.txt`: CPU LegalFactAware and evaluation dependencies.
- `reviewer-controls.txt`: frozen reviewer-control environment.
- `recent-gpu.txt`: DELTA/LCG/Zero-Shot LCS GPU dependencies.
- `inabs.txt`: minimal IN-Abs extension dependency.

These files describe different experiment environments; they are not guaranteed to be jointly solvable in a single environment. Prefer separate virtual environments.
