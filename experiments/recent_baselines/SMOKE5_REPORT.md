# DELTA-Dream 中文法律适配：5 篇冒烟报告

日期：2026-10-31

## 配置

- 数据：冻结 CAIL 开发集前 5 篇；仅用于工程诊断。
- 模型：`Dream-org/Dream-v0-Instruct-7B`，revision `05334cb9faaf763692dcf9d8737c642be2b2a6ae`。
- 解码：DELTA 官方核心算法，CAIL 中文提示适配，4bit NF4。
- 输入：head-tail 8192 Python 字符。
- 输出目标：450 Python 字符，不做事后截断。
- 字符/词元比：`1.5263636665452414`。
- GPU：NVIDIA RTX 4090 D 24GB；峰值显存约 20.3GB。

## 结论边界

长度控制成功，但生成文本出现明显退化，包括数字串重复、英文占位词、主体混淆、
日期与金额错误以及循环句。它不是与现有系统“接近但稍弱”的结果。

因此：

1. 不把 5 篇结果写入论文主表，也不做显著性主张。
2. 不直接投入约 30–40 小时运行 942 篇；这会放大已确认的生成质量问题。
3. 保留完整输出和统一评价记录，作为适配失败的可复查证据。
4. 下一步先更换中文能力更强的自回归模型，并在同一 5 篇上同时检查质量、事实支持和长度。
