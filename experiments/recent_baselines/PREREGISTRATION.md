# 近期基线开发集预注册（2026-10-31）

## 状态与边界

- 状态：开发集实验已启动，正式生成式推理尚未运行。
- 数据：冻结的 CAIL2020-SFZY-clean 开发集 942 篇。
- 测试集：本阶段不读取、不调参、不评价；所有入口仅接收显式传入的 JSONL。
- 任务：输入一篇中国裁判文书，生成不超过 450 个 Python 字符的摘要。
- 本实验只将正式跑完且通过完整性检查的结果写入论文主表。

## 方法身份

1. `LegalFactAware-v2.5-B`：冻结的现有系统输出，用于验证评测口径。
2. `DELTA-Dream-CAIL-adapted`：EMNLP 2026 DELTA 官方解码代码的中文法律适配。它不是作者发布的 CAIL 结果。
3. `DirectPrompt-<model>`：中文能力相近的自回归模型直接接受“不得超过 450 字符”提示；不做输出后截断。
4. `FixedBuffer-Dream-CAIL-adapted`：若资源允许，使用 DELTA 官方固定缓冲区消融，隔离动态长度调整作用。

## 冻结配置

### 共同配置

- `target_chars = 450`
- `max_source_chars = 8192`
- `source_truncation = head_tail`
- 随机种子：42
- 输出保留原样；即使超过 450 字符也不截断。
- 生成方法不设置 8 句上限，因为这是 LegalFactAware 的方法约束，不是任务要求。

`head_tail` 保留前 4096 字符和后 4096 字符。该适配是因为裁判请求通常位于文首、裁判结果通常位于文末。所有生成式方法使用相同输入截取，避免因上下文范围不同造成不公平比较。

### DELTA + Dream

- 官方仓库：`DFKI-NLP/delta-diffusion`
- 模型：`Dream-org/Dream-v0-Instruct-7B`
- `confidence_threshold = 0.65`
- `low_confidence_threshold = 0.95`
- `confidence_metric = probability`
- `max_iterations = 500`
- `initial_gen_length = 500`
- 字符/词元比：仅用开发集 942 篇参考摘要的整体均值估计，已冻结为
  `1.5263636665452414`；后续开发集与测试集均使用该常数。

以上阈值来自 DELTA 论文对 CNN/DM、XSum 的 Dream 配置。它们不在 CAIL 开发集上搜索，以减少额外自由度。若中文小样本出现无法生成等工程错误，只允许修复运行问题；任何阈值变更均需新增预注册版本。

## 主要指标

1. 字符预算：平均、中位数、P95、最大字符数、超预算数量和比例。
2. 目标长度：相对 450 的 MAE，以及误差小于 10/25/50 字符的比例。
3. 摘要质量：字符级 ROUGE-1/2/L F1。
4. 法律表达：金额、日期、法律条文、裁判结果四类的 exact-match micro P/R/F1；同时报告仅参考非空文档上的条件宏平均。
5. 来源支持：预测法律表达在输入原文中出现的比例。
6. 效率：单篇墙钟时间、模型、量化方式和 GPU 型号。

ROUGE 与 Expression 均按文档配对进行 10,000 次 bootstrap 区间估计。Expression 的总体文档宏平均沿用现有正式消融口径：类型两边都为空时跳过；一篇文档四类均为空时记为 1。分类型结果同时给出，避免总体平均掩盖低频类型。

## 决策规则

- 先运行 5 篇工程冒烟测试；只检查可运行性、输出字段和显存，不据此选择阈值。
- 再运行全部 942 篇开发集。
- 开发集结果和配置冻结后，才允许对封闭测试集运行一次。
- 生成式方法与抽取式方法在论文主表中分组呈现。
- 未完成 942 篇、存在 ID 缺失、输出被事后截断或更换过提示词的运行不得进入正式比较。
