# Chinese matched-Oracle control (development set only)

Date frozen: 2026-10-20

## Question

Does imposing the target 450-character budget during summary-level Oracle construction improve the learned sentence scorer, when every other component is held fixed?

## Single changed variable

Both label sets are generated by the same greedy summary-level Oracle using character ROUGE-1 F1 plus character ROUGE-2 F1 and requiring a strictly positive marginal gain.

- **Budget-constrained matched Oracle:** at most 8 complete sentences and at most 450 characters.
- **Budget-unconstrained matched Oracle:** at most 8 complete sentences; the 450-character constraint is disabled only during label construction.

The 8-sentence limit remains active in both conditions so that the character-budget switch is the only changed variable.

## Frozen components

- CAIL clean train/dev split: 7,495/942 documents.
- TF-IDF vocabulary and representation.
- Legal14 and Section6 features.
- Logistic regression: `liblinear`, `class_weight=balanced`, `max_iter=1000`, seed 42.
- Development decoder: complete-sentence greedy selection, 450 characters, at most 8 sentences, redundancy weight 0.2.
- Evaluation: the archived LAWA and character-level evaluation implementations.
- Test split is neither accepted as an argument nor read.

## Primary outcomes

- Development ROUGE-1/2/L F1 under LAWA tokenization.
- Macro Fact F1.
- Paired bootstrap 95% confidence intervals and paired Wilcoxon tests.
- Training-label agreement and document-level selection-change rate.

No hyperparameter or representation choice will be made using the outcome of this control.
